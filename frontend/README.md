# PeeplX - Secure Escrow Platform

A modern, secure escrow platform built with React, TypeScript, and Vite. PeeplX provides a PayPal-style interface for safe transactions with advanced trust verification and security features.

## Features

- **Secure Escrow Management** - Hold and release funds safely
- **Trust Verification** - User verification and trust scoring system
- **Real-time Updates** - Live transaction status and notifications
- **Responsive Design** - Works seamlessly on desktop and mobile devices
- **Modern UI** - Built with Radix UI and Tailwind CSS

## Tech Stack

- **React 19** - UI framework
- **TypeScript** - Type safety
- **Vite** - Lightning-fast build tool
- **Tailwind CSS** - Utility-first styling
- **Radix UI** - Accessible component library
- **GSAP** - Smooth animations
- **Form management** - React Hook Form

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation

```bash
npm install
```

### Available Scripts

- **`npm run dev`** - Start development server with hot module replacement
- **`npm run build`** - Build optimized production bundle
- **`npm run lint`** - Run ESLint to check code quality
- **`npm run preview`** - Preview production build locally

## Project Structure

```
src/
├── components/       # Reusable React components
│   └── ui/          # Base UI components from Radix UI
├── sections/        # Page sections
├── hooks/           # Custom React hooks
├── lib/             # Utility functions
├── App.tsx          # Main application component
├── main.tsx         # Application entry point
└── index.css        # Global styles
```
